# 第2章　社会課題と解決

> ビジョンと現実の差分＝「問題」を洗い出し、原因を突き止め、調査で事実を確かめ、
> 打ち手を決め、ロードマップを引き、10年後の重点政策を決断する章です。

## 2.1. ビジョン・問題・打ち手

**「問題」とは、「現状」と「ビジョン」の差分**です。「問題」の中でも社会全体に関わるものを**「社会課題」**と呼びます。「現状」と「ビジョン」の差分を埋め、「問題」を解決するために行う取り組みが**「打ち手」**です。

「打ち手」とは、行政が行う政策だけではありません。NPOの事業、市民活動、企業の社会貢献活動など、さまざまな主体が「打ち手」を担っています。

本コンテストにおいては、**「30年後の最も見たい未来（＝ビジョン）」**と、**「このまま現状維持で30年後を迎えた場合の日本」**との差分が、解決しなくてはいけない「問題」です。その差分を埋め「問題」を解決するために行う様々な「打ち手」のなかで、特に**行政が行う10年後の政策**を考えていただきます。

:::figure caption="ビジョンと「現状維持で進んだ日本」の差分が「問題」。その差分を埋める手段が「打ち手」です。"
:::grid cols=2
### 30年後（理想）
**最も見たい未来 ＝ ビジョン**

第1章で描いた、あなたが本当に実現したい日本の姿。

### 30年後（現状維持）
**現状維持で進んだ日本**

何の打ち手もしないまま30年が経過した場合の日本の姿。
:::

この2つの**差分**が、解決しなくてはいけない**「問題」**です。

| | 具体例 |
| --- | --- |
| **問題（差分）** | 社会課題、組織課題 など |
| **打ち手（差分を埋める手段）** | 行政の政策、NPOの事業、官民連携事業 など |

このうち本コンテストでは、特に**行政が行う10年後の政策**を考えます。
:::

「問題」とは、「現状」と「ビジョン」の差分である。
:::

## 2.2. 現場の方にうかがう

:::work kind=main id="2-1" title="現場実習先でヒアリングしてみましょう"
ソーシャルインターンシップの現場実習先は全て、何らかの社会課題に取り組んでいます。第1章と同じく、現場実習先の担当者にインタビューのお願いをしてアポを取りましょう。事前にインタビューの目的、所要時間、質問内容を先方に伝え、相手の方に心の準備をしていただく工程を設けましょう。

:::steps
### ステップ1　現場実習先の向き合う問題と打ち手を調べてみましょう
事前に、現場実習先のHP情報やパンフレットなどから、その団体の向き合う問題（社会課題）を調べてみましょう。

問題という表現が見当たらない場合でも、社会課題や困りごとなどの形で表現される場合があります。広くチェックしてみましょう。それでも見当たらない場合は、先方の担当者の方に聞いてみましょう。

### ステップ2　その問題と打ち手に取り組む背景について聞きましょう
ステップ1で調べた問題と打ち手について、どのような理由や考えでその問題に取り組んでいるのかを聞いてみましょう。

- どうしてこの問題が重要と考えたのか
- 取り組む問題にはどのような原因があるのか
- 打ち手が沢山ある中でどうしてそれを選んだのか
- ビジョンと問題と打ち手のつながり

などを幅広く聞いてみましょう。

### ステップ3　調べた内容を、あなたなりに受け止めてみましょう
ステップ1、2で調べた内容について、あなたなりに受け止めてみましょう。調査やインタビューを通じて、あなた自身が共感を覚えた点は何でしょうか。同じく、あなたが新しく関心を持った点や考え方を書き出してみましょう。**自分のプランに取り入れてみたいと思う点**についても書き出してみましょう。
:::

:::note kind="info" title="注釈"
- 主要ワーク1-1のヒアリング先が現場実習先ではなかった場合、担当スタッフに相談し、他のヒアリング先への報告機会を調整してください。
- ヒアリングをせず事例調査をした場合は、「第1章 ビジョン」で調査した自治体の行政計画、NPOの事業報告書などを追跡調査してください。お困りのことは担当スタッフにご相談ください。
:::
:::

## 2.3. 問題の洗い出し

それでは実際に、ビジョンを実現するために解決するべき問題を考えていきます。

:::work kind=sub id="2-2" title="ビジョンと現状のまま迎える30年後を比較したギャップから、問題を洗い出してみましょう"
- ビジョンが実現された30年後の日本の様子を端的に記入してください。
- 何の打ち手もせず迎えた30年後の日本の様子を端的に記入してください。
- その差分＝現在の問題をできるだけ多く記入してください。
:::

:::work kind=sub id="2-3" title="洗い出した問題から重要度の大きな問題を3つ選んでみましょう"
限られた時間、人員、予算の中ですべての問題を解決することはできません。

前ワークで洗い出した問題のうち、特に**ビジョン実現の大きな障害となる、優先度の高い重要な問題**を探しましょう。その影響を及ぼす**範囲がより広い**問題、及ぼす影響が**より深刻**な問題ほど重要です。
:::

## 2.4. 原因の仮説をたてる

:::work kind=sub id="2-4" title="ロジックツリーで原因の仮説を立てましょう"
先ほどあげた「問題」を引き起こしている「原因」を探し出して、解決を試みます。「原因」を探し出すために**「ロジックツリー」**という手法で考えます。

1つの問題に対して、**「だから？」「なぜ？」**という問いを繰り返すことにより、根本的な原因を発見しやすくなります。

ロジックツリーを作成する際は、**「MECE ＝ Mutually Exclusive and Collectively Exhaustive：漏れなく、だぶりなく」**を意識することが大切です。重複していたり、見落としていたりする原因がないか、注意してロジックツリーの作成を行いましょう。

:::figure caption="ロジックツリーの具体例"
:::tree
- 【問題】地方都市の人口が減少し、首都圏に人口が集中している
  - 【原因A】地方から首都圏への転入人口が増加している
    - 【原因A-1】大学などの希望する進学先が地方になく首都圏に存在する
    - 【原因A-2】希望する仕事の求人が地方になく首都圏に存在する
  - 【原因B】首都圏から地方への転出人口が減少している
    - 【原因B-1】地方に転職した場合、賃金水準が下がり生活水準の維持が難しい
:::
:::
:::

:::work kind=main id="2-5" title="現場実習先に相談してみましょう"
ここまでに選び出した問題とその原因の仮説を現場実習先の担当者に報告をしましょう。皆さんが洗い出した問題が現場実習先が取り組む問題と関連する場合、調べた内容は**現場実習先にとってもプラス**となります。

:::note kind="info" title="注釈"
1. 皆さんの取り組みたい問題と、実習先の取り組む問題が異なっている場合があります。実習先の取り組む問題にどの程度沿うか、沿わないかは、皆さんの自由です。実習先の方と相談の上、最終的に皆さん自身で決断してください。
2. 大使館や領事館など、現場実習先の性質によって難しい場合、先のワークでご紹介したヒアリング先、アドバイザー（メンター）、スタッフなどとお話しいただけるよう調整を試みます。スタッフにご相談ください。
:::
:::

## 2.5. 問題・原因の調査

問題と解決すべき原因を考察したら、**調査によって事実かどうか確認**します。確認すべきは次の2点です。

1. その問題が発生しているのは事実か？
2. その原因は事実なのか？

:::work kind=sub id="2-6" title="調査計画を立てましょう"
入手したいデータを明確にして、そのデータに見合った**調査対象／調査方法／調査項目／日時と場所**を計画してください。次の4種類の調査が多く行われています。

:::grid cols=2
### 1. インタビュー調査
個人による発言や行動など数値にできない**「定性データ」**を得るための調査方法。

現場実習先の方に、さらにインタビューをお願いすることも可能です。質問を具体的にして、より詳細なお話を引き出し、有用な定性データを入手してください。

### 2. アンケート調査
人数や割合など何かしら明確な数値や量で表される**「定量データ」**を得るための調査方法。

回答はできるだけ選択式にして、より分析しやすい、有用な定量データを入手してください。

### 3. 文献調査
公表されている調査結果や本、論文などをもとに必要なデータを集める調査方法。

### 4. 統計調査
統計ポータルサイト（[e-Stat](https://www.e-stat.go.jp/)）などのデータベースを利用して必要なデータを集める調査方法。
:::
:::

:::work kind=sub id="2-7" title="現場実習先に相談してみましょう"
調査に着手する前に、現場実習先の担当者に調査計画を報告・相談してみましょう。

インタビューやアンケートの質問項目は人によって解釈が違うこともあるので、**質問の意図が伝わっているかどうか確認する**意味もあります。
:::

:::work kind=main id="2-8" title="調査を実施しましょう"
チームで調査を実施してください。調査をしていて見えてきたことを記録してみましょう。気づいたことは途中段階でチームメンバーにも共有をしてみましょう。
:::

:::work kind=main id="2-9" title="調査結果から問題と原因を特定しましょう"
調査で入手したデータによって、想定していた問題と原因を、**事実として確定**してください。

調査からより根本的な問題や、より根本的な原因を発見した場合は、そちらを確定としてください。問題と影響を及ぼす範囲や深刻さ、その原因、根拠とした調査結果も合わせて記載してください。
:::

:::work kind=main id="2-10" title="現場実習先に報告してみましょう" plansheet
前のワークで検証した結果を、現場実習先の担当者に報告してみましょう。現場実習先の方がこれまでもわかっていた点、新しく気づきがあった点などが存在します。

担当者の意見やフィードバックを受けて、調査結果が妥当かどうかを検討してみましょう。

:::note kind="info" title="注釈"
1. 皆さんの取り組みたい社会課題と実習先の取り組む社会課題が異なる場合、実習先の考えをどの程度取り入れるかについて指定はありません。実習先とよく相談の上、皆さんで決定してください。
2. 大使館や領事館など、現場実習先の性質によって難しい場合、先にご紹介したヒアリング先、アドバイザー（メンター）、スタッフなどがお話しいただけないか調整を試みます。担当スタッフにご相談ください。
:::
:::

## 2.6. 打ち手を決める

:::work kind=main id="2-11" title="打ち手を決めましょう" plansheet
先のワークで突き止めた原因に対する、打ち手を検討します。打ち手にはいくつかのアプローチがあります。代表的なものを以下に3つ挙げます。

:::grid cols=3
### 1. 認知拡大
その問題が世の中で認知され、より軽減されるように働きかける取り組み。促進、訓練など。

（例）節電、リサイクルの推奨、エコフィード認証制度、環境教育、環境学習

### 2. 支援活動
起きている問題に対して、その影響に対処する取り組み。直接的な製品・サービスの提供など。

（例）ゴミを拾う、ごみ処理施設の建設

### 3. 根治予防
その問題が発生する原因を根本的に取りのぞく取り組み。その問題が起きないようにあらかじめ予防をするような取り組み。政策、研究開発など。

（例）消費者・メーカーなどに対するリサイクル法の制定
:::

これを**「問題解決の3つの視点（三象限）」**と呼びます。
:::

:::note kind="column" title="コラム｜「打ち手」と「政策」はどう違うか"
**「打ち手」**とは、「問題」を解決するための取り組み全体です。行政だけでなく、国民・市民、企業、NPO、町内会・自治会、小中学校や高校・大学などが、それぞれの立場で取り組んでいます。

**「政策」**とは、「打ち手」のなかで、特に**行政（国や地方自治体）が行うもの**を指します。

他の「打ち手」と比べた「政策」の大きな特長は、議会が定める**「法律」「条例」などを根拠に、社会全体のルール作りから問題解決に取り組める**ことです。

例えば、「道路上のゴミ」という問題に対して——

- 市民やNPOは、ゴミ拾い活動などで解決に取り組む
- 行政は「政策」として「ポイ捨て防止条例」など**社会全体のルール作り**から解決に取り組む

そのほか、ゴミ拾い活動を補助金によって促進したり、ゴミ拾いイベントに対して「後援：〇〇省」「後援：〇〇市」などの名称を掲げ、社会からの認知を高めるなども「政策」ならではの取り組みといえます。

:::note kind="source" title="出典"
国土交通省 平成30年度 今後の共助による地域づくりのあり方検討会 資料
:::
:::

## 2.7. ビジョン実現までのロードマップ

ビジョンを実現するまでには、複数の重要問題を解決します。重要問題を解決するためには、それぞれに複数の政策を実行します。政策には同時に実行するもの、順番を決めて実行するものがあります。

ビジョン実現までの問題解決、政策の実行順をまとめると**ロードマップ**ができます。このロードマップがあって「**10年後に実施する重点政策**」を決定して提言することが可能になります。

:::roadmap
### 本年（現在）
- 問題1
- 問題2
- 問題3

### 10年後
* 政策A
* 政策B
* 政策C

### 20年後
- 政策D・E・F
- 打ち手D・E・F（行政以外の主体も含む）

### 30年後
- 政策G〜L
- 最も見たい未来＝ビジョンの実現
:::

色を付けた**10年後の3つ**が、皆さんが提言する「重点政策」です。ロードマップ全体があるからこそ、「このロードマップを根拠に、10年後はコレをやる」と言い切ることができます。

:::work kind=sub id="2-12" title="政策を書き出してみましょう"
先のワークで挙げた打ち手のうち**「根治予防」の枠内**で、政策にあたるものを書き出してみましょう。足りなかった政策があれば、ここで追記してください。
:::

:::work kind=sub id="2-13" title="何年後に着手するのかを決めましょう"
前ワークで列記した政策に、**何年後に実施するか**書き添えましょう。目安は次の通りです。

| 着手時期 | 目安 |
| --- | --- |
| **1〜5年後** | 実行の決断をすればできる政策 |
| **5〜10年後** | 最新技術の普及や予算を複数年確保など、準備期間がわかっているもの |
| **10年後以降** | 大きな制度変更や国民への説得・浸透など、準備期間がはっきりしないもの |

:::note kind="example" title="考え方の例"
**ビジョン：** 住民全てが、自主的に学ぶ意欲を持っている国。それにより生産性が向上し、世界で活躍するリーダーを輩出する。

**問題1：子どもが自主的に学ぶ機会がない**

原因

1. カリキュラムに沿った学習内容で、自己決定が少ない
2. 自分の興味のある社会教育に触れる機会が少ない
3. 自主的に学習をする時間が足りない
4. 通信環境によって学ぶ手段に差異がある

政策

- ① 学校制度の転換 → 10〜20年後／独自指導要領導入 → 20〜30年後
- ② 企業と連携した専門教育 → 5〜10年後
- ③ 登校日を週5から週3に → 10〜15年後
- ④ オンライン教育制度の整備 → 1〜5年後

**問題2：生涯学習の機会や時間が確保されていない**

原因

1. 仕事をしながら学習をする時間がない
2. 終身雇用により新たなスキルを必要とする機会が少ない
3. 企業が人材育成にコストを割きにくい

政策

- ① 週休4日制 → 10〜20年後
- ② 誰もが副業を持つ → 10〜20年後
- ③ AI導入による無駄の削減 → 5〜10年後／機械化による無駄の削減 → 1〜5年後
:::
:::

:::work kind=main id="2-14" title="ロードマップを作成しましょう" plansheet
主な政策を1つのロードマップに集約してください。その時期の政策によって**日本がどう変化するのか**、一番右の列に変化も記入してください。着手年の割り振りは前のワークも参考にしてください。

※ここまでできたらプランシートの**ロードマップ**に転記しましょう。
:::

:::work kind=sub id="2-15" title="10年後に行う重点政策を決めましょう"
最後に、ロードマップの**10年後に着手する政策**から、**3つの重点政策**を決断しましょう。
:::

## 2.8. 重点政策を詳細化する

ビジョン実現までの全体像から、いよいよ10年後の重点政策に焦点を絞り練り上げていきます。

:::work kind=main id="2-16" title="重点政策の細部を決めましょう"
政策は以下5つが決まっていないと実行できません。**重点政策ごとに**5点を書き出しましょう。

| | 決めること |
| --- | --- |
| **1. 目的** | 何のために政策を行うのか |
| **2. 対象者** | 誰に対して政策を行うのか |
| **3. 主体** | 誰が政策を行うのか |
| **4. 期間** | どのくらいの期間で政策を行うのか |
| **5. 内容** | どのような政策を行うのか |
:::

:::note kind="column" title="コラム｜政策の手段"
政策の手段は大きく3つに分類することができます。

#### 1. 直接供給・直接規制

自治体が社会に対して直接介入を行います。自治体が直接サービスや財を提供する「直接供給」と、自治体が制限を行う「直接規制」があります。

| 直接供給 | 例 | 直接規制 | 例 |
| --- | --- | --- | --- |
| 自治体にしか行えない | 生活保護、公園整備 | 経済的規制 | 土地区画整理 |
| 民間だけでは足りない | 交通、防災 | 社会的規制 | 景観保全 |

#### 2. 誘導（誘引）

自治体が社会を誘導するための仕組みを作ります。個人や企業に特定の行動を取らせたり、逆に取らせないようにしたりする手段です。

| プラスの誘引 | 例 | マイナスの誘引 | 例 |
| --- | --- | --- | --- |
| 何かをさせる | 補助金、減税、融資 | 何かをさせない | 課税、罰金 |

#### 3. 情報提供

特定の情報を与える手段です。情報によって意識を変化させ、行動を変化させます。

| 情報提供 | 例 |
| --- | --- |
| 意識を変化させ、行動を変化させる | 講演会、パンフレット |
:::

## 2.9. 重点政策とビジョンの整合性

:::work kind=main id="2-17" title="変革仮説で検討してみましょう"
これまでとは逆に、**「10年後の重点政策」から見て「ビジョン実現までの30年間」は成り立つのか？** 検討してみましょう。

「10年後の重点政策」が起こす変化、その変化が起こす次の変化、さらにその変化が起こす次の次の変化…と、**因果関係に沿って考察を繰り返し**、最後にビジョンの実現に貢献すればベストです。この検討手法を**「変革仮説」**といいます。

「10年後の重点政策」を変革仮説で検討した結果、どうしてもビジョンにつながらない、ズレてしまう場合は、**重点政策の改訂も検討**してみましょう。

:::figure caption="変革仮説の記載例：ドットジェイピーの場合"
:::flow
- 良質なインターンシッププログラムを提供する
- 学生がインターンに参加する
- 議員と触れ、政治の現場を知る／コンテストを通じて政策に触れる
- 政治の重要さを知る
- 選挙で投票を行う
- 若年投票率が上がる
- 最も見たい未来が実現する
:::

あわせて、次のような**副次的な循環**も生まれています。

- プログラムに気づきがフィードバックされ、さらに改善される
- インターンが口コミで広がり、受講者が増える
:::
:::

## 2.10. 社会的インパクトの見積もり

> **社会的インパクト ＝ 実行した結果（アウトプット）によって、社会にもたらした様々な成果（アウトカム）全体**

たとえば「雇用促進イベント来場者〇〇人」といった結果（アウトプット）ではなく、その結果がもたらした「イベント来場者の意識変化」や「イベントがきっかけで発生した雇用」など、複数の成果（アウトカム）全体を指します。

政策の社会的インパクトを見積もることで、政策が社会へもたらす具体的な影響を推し量って、より有用になるよう検討することができます。社会的インパクトを見積もる方法として、簡易的な**「ロジックモデル」**という手法を使います。

:::work kind=main id="2-18" title="政策の定性的な成果を想定しましょう"
それぞれの重点政策が、具体的にどのような成果をもたらすかを**時系列や範囲の大きさに分けて**書き出します。

ワーク2-17「変革仮説で検討してみましょう」で書き出した政策の因果関係を参考にして、以下の4つの項目を定性的に書き出してみましょう。

| 項目 | 期間 | 内容 |
| --- | --- | --- |
| **取り組む活動** | 1年程度 | 短いスパンで具体的に取り組む活動内容 |
| **活動の結果** | 1年程度 | 具体的な活動の結果 |
| **短中期的な成果** | 3〜5年程度 | 具体的な活動の成果 |
| **長期的な成果** | 10年程度 | 長期的な活動の成果、広く社会に影響をもたらすような広範囲な成果（社会的インパクト） |

:::note kind="example" title="記載例：障がい者の方向けの職業訓練を行う"
| 項目 | 内容 |
| --- | --- |
| **取り組む活動**（1年程度） | 訓練講座を開催する／障がい者の方が受講 |
| **活動の結果**（1年程度） | 受講者が就労する／就労して賃金を得る／受講者の意欲向上 |
| **短中期的な成果**（3〜5年程度） | 継続して働く |
| **長期的な成果**（10年程度） | 障がい者が自立できる社会が実現する |
:::

:::note kind="info" title="モデルペース一覧との表記差について"
本ワークは、ワークのページ上では【主要】ワークとして記載されていますが、[スケジュールのモデルペース一覧](schedule.html)では［補助］ワークとして記載されています。判断に迷う場合は担当スタッフにご確認ください。
:::
:::

:::work kind=sub id="2-19" title="政策の定量的な成果を想定する"
前のワークで書き出した定性的な成果に対して、**具体的に実現可能な数値目標**を記載してみましょう。

:::note kind="example" title="記載例：障がい者の方向けの職業訓練を行う"
| 項目 | 数値目標 |
| --- | --- |
| **取り組む活動**（1年程度） | 講座回数：5回／受講者数：100人／専門機関での講座開催委託費：50万円 |
| **活動の結果**（1年程度） | 就労人数：10人／一人が得た賃金：100万円（年収）／平均就労期間：1年 |
| **短中期的な成果**（3〜5年程度） | 平均就労期間：3年間／就労満足度：4.1 |
| **長期的な成果**（10年程度） | 10年間の就労延べ人数：100人 |
:::
:::

:::work kind=main id="2-20" title="社会的インパクト（成果全体）を見積もりましょう"
前のワークで書き出した成果の定量的な数値を元にして、その重点施策がもたらす**成果（社会的インパクト）全体**を見積もってみましょう。

:::note kind="example" title="記載例"
**経済効果** — 雇用創出による賃金増　約 30,000,000円（10年間）

**算出根拠**

- 10年間の就労延べ人数：100人
- 平均就労期間：3年間
- 一人あたりの平均賃金：100万円（年間）
:::
:::

## 2.11. 重点政策を精錬する

重点政策の内容をより深みのあるものへ練り上げるため、ビジョンと同じく**外部の人からのフィードバック**を受けましょう。

様々な方々に重点政策を説明し、フィードバックを受ける過程を通じて、様々な賛同意見や建設的な批判に触れ、あなたの重点政策はより精錬されていくでしょう。

:::work kind=main id="2-21" title="現場実習先へ報告してみましょう" plansheet
本ワークでは、現場実習先の担当者にプレゼンテーションをしてみましょう。[1.4で示したような段取り](vision.html#s1-4)で、担当者の方に事前のアポを取りましょう。

:::steps
### ステップ1　重点政策を発表しましょう
あなたのチームが作った重点政策を発表してみましょう。単純に内容を伝えるだけではなく、その背景に**どのような自分自身の課題意識があるのか**、検討をしたプロセスを含めて発表しましょう。

### ステップ2　フィードバックを受けましょう
ステップ1で発表した内容について、相手の方からのフィードバックを受けましょう。フィードバックの視点として、**共感を覚えた点、共感が弱い点**（改善をすることでさらに共感が強くなる余地のある点）について、意見を述べてもらいましょう。

もし、その他に指摘やフィードバックをいただいた場合はそれもメモに残しましょう。

### ステップ3　フィードバックを受け止めましょう（取捨選択）
相手の方からいただいたフィードバックの内容を元に、あなたのチームの重点政策で修正したいと感じる点があれば、それを書き出しましょう。

ここで十分に留意いただきたいのは、**あなたのチームが描くビジョンのオーナーは「あなた自身」**です。全てのフィードバックを飲み込みビジョンに反映をする必要はありません。あなたが、相手の方の考えやフィードバックを受け止め、その上でそれをビジョンに反映するかどうか、あなた自身で判断（＝取捨選択）をしてください。

### ステップ4　精錬した重点政策
フィードバックは、できれば**複数の方**からいただくことが理想です。フィードバックを受け、取捨選択した内容を、元の重点政策に反映しましょう。
:::

:::note kind="info" title="注釈"
大使館や領事館など、現場実習先の性質によって難しい場合、ご紹介したヒアリング先、アドバイザー（メンター）、スタッフなどとお話しいただけるよう調整を試みます。担当スタッフにご相談ください。
:::
:::
