# 大会とルール

> キックオフから全国決勝大会まで、何がどの順番で行われるのか。
> 発表時間・評価方法・採点者は大会ごとに違います。ここで押さえておきましょう。

## 0.3. 全国決勝大会までの道のり

プログラムは、**現場実習（実社会の現場からの学び）**と**座学（キックオフ・レクチャーからの学び）**の両輪で進みます。

:::timeline
### 1. キックオフ
全体概要・やるべきことの確認と、ビジョン・政策の考え方を学びます。

- コンテストのルール・やるべきことの理解
- ビジョン・政策の理解
- 30年後の日本のビジョン設定

### 2. プレゼン講座
プレゼンテーションをする上での心構えを学びます。

- プレゼンテーションをするうえでの心構え／ノウハウの理解

### 3. ハーフタイム
作成したプラン（政策立案まで）を持ち寄ります。さらに予算の立て方・プレゼンに関する具体的なノウハウを学びます。

- 調査を通じた現状の確認
- 具体的な政策の立案
- 予算の理解

### 4. 地方決勝大会
参加全チームが出場します。作成したプランについて主に参加者同士に向けプレゼンテーションと質疑応答を行い、**地方決勝大会最優秀チーム**を決定します。

- プレゼンテーション
- 質疑応答
- 予算の策定
- 地方決勝大会最優秀チームの決定

### 5. 全国準決勝大会
地方決勝大会最優秀チームが進出します。主に視聴者や有識者に向けプレゼンテーションとミニ・パネルディスカッションを行い、**全国上位4チーム**を決定します。

- プレゼンテーション
- パネルディスカッション
- 全国上位4チーム決定

### 6. 全国決勝大会
全国上位4チームが進出します。視聴者に向けプレゼンテーションとパネルディスカッションを行い、「最も見たい未来」を提唱した**全国最優秀チーム**を決定します。

- プレゼンテーション
- パネルディスカッション
- 全国最優秀チームの決定
:::

:::note kind="info" title="オンラインレクチャー"
座学からの学びを補うものとして、次のオンラインレクチャーが用意されています。

- ビジョン編
- 社会課題と解決編
- 政策編
- スライド編
:::

## 0.4. 各大会の詳細

| | 地方決勝大会 | 全国準決勝大会 | 全国決勝大会 |
| --- | --- | --- | --- |
| **出場チーム数** | 多数のチーム | 20〜30チーム | 4チーム |
| **評価者** | 参加者同士・観覧者 | 視聴者・有識者 | 一般の観覧者の若者全員 |
| **形式** | 会場（対面／一部オンライン） | オンライン（YouTube限定配信） | 会場 |

### 大会における評価方法

- **採点**：[評価規準](intro.html#hyoka)の5つの規準について、各評価規準 **7点、計35点満点**として行います。地方決勝大会では参加者同士が採点し、全国準決勝大会 午前の部では視聴者が採点します。
- 全国準決勝大会 午後の部では視聴者と有識者が採点し、全国決勝大会では観覧者のみ採点します。

### STEP 1：地方決勝大会

約30エリアごとに開催し、**全参加チームが出場**してエリア内最優秀チームを決定します。会場に集まり対面で行いますが、状況によりオンライン実施エリアもあります。また観覧者がいるエリアもあります。

#### 発表ルール

プラン発表はプレゼンテーションと質疑応答で構成されます。

:::grid cols=2
### プレゼンテーション
時間は**10分間**です。

※制限時間を過ぎますと、途中でも終了とすることがありますのでご注意ください。

### 質疑応答
時間は**5分間**です。他のチームや観覧者からの質問に対して回答してください。

※制限時間を過ぎますと、途中でも終了とすることがありますのでご注意ください。
:::

#### 評価ルール

- **【評価方法】採点** — 先述の5つの評価規準について各7点、評価者1人につき合計35点満点で採点します。獲得した点数を平均化し、その平均点が最も高いチームが地方決勝大会の優勝となります。
- **【評価者】参加者同士・観覧者** — 会場にいる参加者全員および観覧者のうち、**全チームの発表を観た方のみ**採点できます。

:::note kind="warn" title="「全チームの発表」の範囲"
「全チームの発表」とは自分が参加／観覧している**会場での全ての発表**を指します。

（例）A／B／Cと3会場に分かれて実施されている場合、A会場での採点ができるのは、A会場での各チームの発表を全て観ている参加者および一般観覧者だけです。

※参加者は自チームを採点できません。
:::

### STEP 2：全国準決勝大会

各エリアの地方決勝大会に優勝したチームから、全国決勝大会へ進出する**全国上位4チーム**を決定する大会です。オンライン上で行い、YouTubeで本コンテスト参加者に対してのみに限定しライブ配信します。

:::steps
### 地方決勝大会優勝チームを4ブロックに分ける
さらに各ブロックを第一部・第二部に分けます。

### 午前：同ブロック内で部ごとに競う
第一部1位、第二部1位を決定します。

### 午後：ブロック内決戦投票
第一部1位と第二部1位でブロック内決戦投票を行い、ブロック内1位を決定します。

### 全国決勝大会へ
各ブロック内1位のチーム、合計4チームが全国決勝大会へ進出します。
:::

:::flow
- A・B・C・Dの4ブロックに振り分け
- 各ブロック 第一部／第二部で採点
- 各部1位同士で決戦投票
- ブロック内1位＝全国上位4チーム
:::

#### 発表ルール

プラン発表はプレゼンテーションとミニ・パネルディスカッションで構成されます。午前の同ブロック内第一部1位と第二部1位の決定、午後の各部1位同士のブロック内決戦のいずれも構成は同じです。

- **【プレゼンテーション】** 10分間です。発表用Googleスライドを画面上で共有して行います。
- **【パネルディスカッション】** 午前は参加チーム代表者全員と視聴者で討論します。討論は、出席者全員が司会の提起する観点から意見を出し合う形式で進行します。プレゼンテーションで伝えきれなかったことを発言し、視聴者にアピールしてください。午後の各部1位同士のブロック内決戦に関しては、さらに有識者も交えて行います。

:::note kind="warn" title="Googleスライド以外は減点"
Googleスライド以外（Canvaなど）のツールを使用した発表があった場合、**総合点数より1割減点**されますのでご注意ください。
:::

#### 評価ルール

- **【評価方法】** 午前の同ブロック内第一部1位と第二部1位の決定に関しては採点で評価します。先述の5つの評価規準について各7点満点、計35点満点で採点します。点数の処理方法は地方決勝大会と同様です。
- 午後の各部1位同士のブロック内決戦に関しては、視聴者からの採点数に**有識者の評価を加えて処理**し、最も得票数が多いチームがブロック内1位となります。
- **【評価者】視聴者・有識者** — 視聴者はブロックごとの全参加者です。ただし全国準決勝大会の参加者自身は除きます。有識者の顔ぶれは別途お知らせします。

### STEP 3：全国決勝大会

地方決勝大会優勝の全チームから勝ち上がった4チームが、優勝を目指し競う**最後の大舞台**です。会場、開始時刻等の詳細は別途お伝えします。

#### 発表ルール

プラン発表はプレゼンテーションとパネルディスカッションで構成されます。

- **【プレゼンテーション】** 10分間です。発表用パワーポイントを画面上で共有して行います。発表に対して観覧者からの質問を受付、質疑応答を5分間行います。
- **【パネルディスカッション】** 全国決勝大会進出チーム全員とゲストで討論します。ゲストからの各チームに対する質問を中心に進行します。質問は、司会が提起するいくつかの観点を踏まえ、複数回行われます。プレゼンテーションで伝えきれなかったことを発言し、視聴者にアピールしてください。

#### 評価ルール

- **【評価方法】採点** — 視聴者1人につき1票とし、プレゼンテーションとパネルディスカッション、及びプランシートから、5つの評価規準を念頭に「最も見たい未来」を提唱したチームに投票します。最も得票数が多かったチームが全国最優秀チームとなります。
- **【評価者】一般の観覧者の若者全員** — ※ゲスト、全国決勝大会の参加者自身には採点権がありません。

:::note kind="tip" title="残念ながら上位大会進出を果たせなかった皆さんへ"
残念ながら上位大会進出を果たせなかった皆さんも、後日、YouTubeにアップロードされる全国準決勝大会を視聴してください。進出したチームから、残念ながら自分達にわずかに欠けていた点に気づき、逆に**自分達ならではの長所を発見**することができるでしょう。

また全国決勝大会は東京で開催しますが、観覧のご都合がつくようであれば、是非観覧へお越しください。
:::
