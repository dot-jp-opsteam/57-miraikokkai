# 未来国会2026 テキストブック（Web版）

NPO法人ドットジェイピー「未来国会2026」の国家デザイン テキストブック（配布PDF・全108ページ）を、
参加者がスマートフォンでも読めるように再構成した静的サイトです。

- **公開先**：GitHub Pages（`Settings → Pages` の URL）
- **正本は配布された PDF です。** 本サイトは読みやすさのための内部資料であり、記載に差異がある場合は PDF を優先してください。

## できること

- 章・節ごとのページ分割と、追従する目次
- ワークの **【主要】／［補助］** の色分けと、チェックによる進捗管理（ブラウザのローカル保存のみ）
- サイト内全文検索（`/` キー）
- ダークモード、印刷用レイアウト、モバイル最適化

## 収録できていない箇所

配布PDFのうち、**画像として作られているページ**はテキストを取り出せなかったため未収録です。

## 構成

```
content/        本文（Markdown）。編集するのは基本ここだけ
assets/         style.css / app.js
build.py        content/ → dist/ を生成する静的サイトジェネレータ
check.py        出力された HTML の検証（リンク切れ・タグ崩れ）
dist/           ビルド成果物（Git 管理外）
```

## 編集して公開するまで

```bash
python3 build.py     # dist/ を生成（Python 3.9+ / 追加ライブラリ不要）
python3 check.py     # リンクとタグの検証
python3 -m http.server -d dist 8000   # http://localhost:8000 で確認
```

`main` または `claude/future-diet-textbook-html-5n7n8z` ブランチに push すると、
GitHub Actions（`.github/workflows/deploy.yml`）が自動でビルドして Pages に公開します。

## 本文の書き方

`content/*.md` は Markdown のサブセット（見出し・箇条書き・表・リンク・強調）に加えて、
`:::ブロック名` 形式の記法が使えます。

### ワーク

```markdown
:::work kind=main id="1-1" title="現場実習先でヒアリングしてみましょう" plansheet
本文…
:::
```

| 属性 | 意味 |
| --- | --- |
| `kind` | `main`＝【主要】ワーク（オレンジ）／`sub`＝［補助］ワーク |
| `id` | `1-1` のようなワーク番号。チェック状態の保存キーになる |
| `title` | ワークの見出し |
| `plansheet` | 付けると「プランシートへ転記しましょう」の帯が出る |

ワークは `content/works.md` の `:::worklist` に自動で一覧化されます。

### そのほかのブロック

| 記法 | 用途 |
| --- | --- |
| `:::note kind="tip\|warn\|info\|column\|example\|source" title="…"` | 補足・注意・コラム・記載例・出典 |
| `:::steps` | `###` 見出しごとに番号付きのステップ |
| `:::grid cols=2\|3\|4` | `###` 見出しごとのカード |
| `:::timeline` | `###` 見出しを時点ラベルにした時系列 |
| `:::flow` | `- ` の各項目を矢印でつないだ流れ図 |
| `:::tree` | 入れ子の箇条書きをロジックツリー表示 |
| `:::figure caption="…" [kind=missing]` | 図版の枠。`kind=missing` は未収録を示す破線枠 |
| `:::stats` | `- ラベル：値` を数値カードで表示 |
| `:::hero kicker="…" title="…"` | 見出し用の大きめのブロック |
| `:::linkcards` | `- [表示名](URL) \| 小見出し \| 説明` のリンクカード |

ブロックは入れ子にできます（開始は `:::名前`、終了は `:::` のみの行）。

### 見出しとアンカー

`## 2.4. 原因の仮説をたてる` のように節番号で始めると、アンカーは `#s2-4` になります。
番号がない見出しに固定のアンカーを付けたいときは `## 評価規準 {#hyoka}` と書きます。

## ナビゲーションにページを足す

1. `content/` に Markdown を追加する
2. `build.py` の `PAGES` にスラッグ・表示名・ファイル名・グループを追記する
